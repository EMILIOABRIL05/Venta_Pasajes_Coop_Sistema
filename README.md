# Sistema-Web-de-Gesti-n-y-Venta-de-Pasajes-para-Cooperativa-de-Transporte-Interprovincial
Aplicación web para la gestión operativa, control de hojas de ruta y venta de boletos con código QR para una cooperativa de transporte interprovincial en Ecuador. Desarrollado con Laravel 11, Livewire y PostgreSQL bajo un entorno Docker.
